# data-import-scripts
Scripts to handle data import from various lab equipment

# BLATN BR-SMART
- Amazon: https://www.amazon.com/dp/B08YKG13KY
- Exports data to a microSD card
- Formatter script:
	- Adds units
	- Converts from native plaintext to Excel-friendly CSV

# Tube Furnace MCGS HMI
- Exports data to a FAT-32 formatted USB drive
- Formatter script:
	- Adds units
	- Switches headers from Chineese to English
	- Outputs Excel-friendly CSV
